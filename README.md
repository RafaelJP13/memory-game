🧠 Memory Game
Um jogo da memória clássico construído com HTML, CSS e JavaScript. Desafie sua memória encontrando pares de cartas em um tabuleiro interativo e divertido! 🎴
📖 Sobre o Projeto
O Memory Game é uma aplicação web que implementa o tradicional jogo da memória. O objetivo é simples: vire duas cartas por vez para encontrar pares correspondentes. Com uma interface responsiva e animações suaves, é perfeito para todas as idades! 🧩
✨ Funcionalidades

🎲 Embaralhamento aleatório das cartas a cada partida.
🏆 Contador de tentativas para acompanhar seu desempenho.
✅ Feedback visual para acertos e erros.
📱 Design responsivo para desktops e dispositivos móveis.
🔄 Botão de reiniciar para novas partidas.

🛠️ Tecnologias Utilizadas

HTML5 - Estrutura da interface.
CSS3 - Estilização e animações das cartas.
JavaScript - Lógica do jogo e interatividade.

🎮 Como Jogar

Clique em uma carta para revelá-la.
Clique em outra carta para tentar formar um par.
Se as cartas combinarem, elas permanecem viradas. Caso contrário, elas se escondem novamente.
Continue até encontrar todos os pares!
Clique em "Reiniciar" para começar uma nova partida. 🚀

🚀 Como Executar
Siga os passos abaixo para rodar o projeto localmente:

Clone o repositório:
git clone https://github.com/RafaelJP13/memory-game.git


Navegue até o diretório:
cd memory-game


Abra o arquivo index.html no seu navegador preferido.
Alternativamente, use uma extensão como Live Server no VS Code para uma experiência de desenvolvimento mais dinâmica.
